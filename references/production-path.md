# 成稿路径与翻译腔根治（H23–H27 · 公共核）

> **根因**：客户长期觉得「像翻译腔」，多半不是少洗一遍，而是成稿路径不对。  
> **原则**：先人话定稿 → 冻结数字 → Agent 贴句/落格；机器只检出翻译腔，**改写用人或句库**，禁止多模型互洗。  
> 与 `delivery-artifact-mode.md`（H18–H22）叠用；句式扫描见 `phrase-blacklist.md` §21；正反例见 `rewrite-patterns.md` §33–36。

---

## H23 · 强制生产顺序：中文定稿句先于出图

### 错误路径（禁止当默认）

```text
Agent 按规划稿/词表直接灌 PPT → 事后去 AI 腔 / 换模型二改
```

### 正确路径（客户/请示 PPT 默认）

| 步 | 谁 | 产出 | Agent 可否代劳 |
|----|-----|------|----------------|
| 1 | 口径主笔（人或指定角色） | 该页完整中文短句：数据 / 结论 / 建议（先说出口或写入 md） | **否**（Agent 可催问、可整理口授，不得凭空造句） |
| 2 | 口径主笔 | 冻结数字与口径表 | 可协助登记，不可改数 |
| 3 | 版式轨 | 贴入定稿句；布局只动框/字号/图 | **是**；**默认不改写句式** |
| 4 | 通顺审稿人（真人） | 出声读；只标别扭处 | Agent 可代列问题，**签字位必须是人** |
| 5 | FIX | 句库替换或人改；再扫翻译腔句式表 | 命中硬检不得「再洗一遍」放行 |

**门禁**：无「中文定稿句」证据（md/纪要/主笔确认）却直接出客户 PPT → **Blocker**（路径违规）。  
内部草稿可豁免，须在报告注明「内部路径，非客户交付」。

**Agent 贴句铁律**：

- 有定稿句 → **逐字粘贴**（可折行、可删多余空格），禁止同义改写
- 无定稿句 → 停下来要主笔句，或只输出「待主笔填写」骨架，禁止灌满翻译腔正文

## H24 · 句库优先：组句不造句

项目覆盖层应维护「客户认可句库」SSOT（公共核不写机构专句）。  
公共核句库骨架随包位于 `references/sentence-bank/`（README / WORKFLOW / entries / pages / freeze / approved-pages）；
项目专属认可句由项目覆盖层维护，约定放项目自建目录 project/sentence-bank/（不随公共核分发，包内无此路径）。

### 句库条目最小字段

| 字段 | 说明 |
|------|------|
| id | 稳定编号 |
| text | 已获认可的完整中文句 |
| scene | 可用场景（问题/优势/矩阵/定额/封面导语…） |
| freeze_numbers | 句内不可改的数字/口径 |
| slots | 可替换变量位（如 `{客群}` `{切点}`） |
| source | 哪一版客户说过「可以」 |

### Agent 默认行为

1. 新稿**优先拼句库**，只写增量句（句库没有的新事实）
2. 默认 **组句不造句**：拼装、填槽、删句；禁止整页重写
3. 句库句与冻结数字冲突 → **Blocker**，回主笔，不擅自改句库
4. 无句库时：用 H27 few-shot 样例页约束节奏，仍禁止空转大段造句

## H25 · 翻译腔句式硬检（命中打回）

在禁词表之外，增加**句式级**硬检。机器**只做检出**；改写必须人改或句库替换。  
禁止：「检出 → 自动换模型洗稿 → 再交」作为唯一修复路径。

| 类型 | 信号（例） | 级别 |
|------|------------|------|
| 欧化长定语 | `通过…进行…从而实现…`；一句内「的」链过长且无停顿 | 对外 **Blocker** |
| 空转动词 | `进行开展` `予以落实` `完成构建` `做好…工作` `开展…工作` | **Blocker** |
| 假对称堆砌 | 「一是…二是…三是…」且每条句式完全同构，超过半页或 ≥4 条无信息差 | **Blocker** |
| 名词串 | `数据整合能力建设路径安排`；≥4 字名词粘连无动词 | **Blocker** |
| 英文思维残留 | 过度 `基于` `在…背景下` `作为…的一部分` `通过…来…`（无必要） | 密集 **Blocker** / 零星 Warning |

细则词表：`phrase-blacklist.md` §21。与 H19 关系：H19 管框式虚动词；H25 管**整句构式与假排比**，更严、可单独打回。

## H26 · 分人分轨（禁止同一 Agent 又编数又修文）

| 角色 | 只做 | 不做 |
|------|------|------|
| 口径主笔 | 中文句、数字、归因 | 不调框、不「润色到认不出」 |
| 版式 Agent | 框、图、字号、折行 | **不改句式、不改数** |
| 通顺审稿人 | 只读出声（建议每页 ≥2 分钟），标别扭 | 不改数；改句走人改/句库 |
| GATE Agent | 只审列出 H18–H27 / D1–D8 | 不顺手改稿 |

同一会话若切换角色，须显式声明当前轨；混轨导致改数 → 按 D2 **Blocker**。

## H27 · 单页限额 + 己方好页 few-shot

### 单页限额（客户/请示正文页）

| 限额 | 规则 |
|------|------|
| 结论 | ≤ **2** 句完整中文 |
| 建议 | 只写**动作**（谁/做什么），**不重复**结论句 |
| 并列 | 禁止半页「优势一二三四五」同构灌满；超限则拆页或删句 |
| 证据 | 数据点宜 ≤3 组；每组须能挂到结论 |

翻译腔最爱出现在「优势一二三四五」一气灌满时；**拆页或删句**优先于再洗。

### few-shot（比换模型更有效）

1. 抽 **3～5 页**客户说过「这段可以」的历史页（项目覆盖层维护路径）
2. 新写强制对齐：句长、节奏、是否采用「数据/结论/建议」结构
3. 提示锚定具体书面语样本（由项目提供样段），**禁止**只写「专业、全面、赋能」类空约束
4. 无样例时仍执行单页限额 + H25，不得用空形容词代替样例

## 明确不建议当主方案（写入政策）

| 做法 | 为何不作为主路径 |
|------|------------------|
| 英→中再洗 / 中→英→中来回译 | 加重翻译腔 |
| 多模型接力润色 | 常越洗越像说明书；且易口径漂移 |
| 只加禁词、不改「谁先写中文」 | 治标不治本 |
| DeepSeek/他模二改作唯一手段 | 可作人改前的**可选**草稿，不得跳过主笔定稿与硬检 |

允许：主笔定稿后，将**已冻结片段**交外模润色建议 → 人择优 → 句库或手改回写 → 再跑 H25。

## GATE 判级补丁

| 码 | 条件 | 级别 |
|----|------|------|
| H23 | 客户交付无定稿句证据却全文 Agent 造句 | Blocker |
| H24 | 有句库却整页重写且未声明增量 | Warning；数字被改 → Blocker |
| H25 | 欧化长定语/空转动词/假对称半页/名词串 | Blocker |
| H26 | 版式轨改了数或句式 | Blocker（改数）/ Warning（改句） |
| H27 | 结论>2句或同构并列灌满半页 | Warning；对外请示升 Blocker |
