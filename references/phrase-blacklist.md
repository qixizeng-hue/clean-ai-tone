# 公共禁用词与替换表

> 跨项目通用。含数据分析/风控常见套话的**中性**替换；不含单一机构专有隐喻（那些放项目层）。

## 1. AI 套话

| 禁用 | 替换为 |
|------|--------|
| 单点定生死 | 不宜仅凭单一分数或单一指标决策 |
| 一手依据 | 主要参考 |
| 清晰路径 / 合理建设路径 | 建议按数据、规则、模型（或项目既定）顺序推进 |
| 一体化决策工具 | 直述要联动的具体能力（如额度、复核），不用工具隐喻 |
| 量化仪表盘 / 核心指标看板 | 指标看板 / 指标表 |
| 从「…」升级为「…」 | 直述目标能力，不用升级隐喻 |
| 一句话总结： | 总结： |
| 全文结论可归纳为 | 结论如下 |
| 【核心判断】/ 核心判断 | （删除标签） |
| 综上所述 / 不难看出 / 值得一提的是 | （删除或并入正文） |
| 值得注意的是 / 需要指出的是 / 更微妙的是 / 还有一层 / 只说对了一半 / 从某种意义上说 / 总而言之 / 由此可见 / 不仅如此 / 归根结底 / 毋庸置疑 / 不言而喻 / 如前所述 | （删除；下句能自立就直删，勿换成「总之 / 说到底」） |
| 说白了 / 说穿了 / 先说结论 | （删除，直陈后句） |
| 终局（终局好坏、终局标签） | 最终 |
| 影子试算 | 预演试算 |

| 显著高于 / 显著低于 | 高于 / 低于 |

| 堪称 / 令人 | （删除） |

## 3. 贬义定性

| 禁用 | 替换为 |
|------|--------|
| 短板 / 洼地 / 天花板 | 提升空间 / 后续重点 |
| 失效 / 误杀 | 需复评校准 / 可优选但仍被拒绝的情形 |
| 不足（泛化） | 仍有提升空间 |
| 恶化加速 | 风险上升 |

## 4. 模板空句（整句删除重写）

- 见图表及关键指标。指标变化直接影响…
- 需结合相邻章节图表交叉验证，避免单一指标误判
- 见图表轴标签、图例及数据标签中的具体数值
- 建议关注 / 持续优化（无数、无动作时）
- 截至今日 / 截至目前（后文无具体日期时）→ 改具体日期「截至2026年10月18日」，或标【日期待确认】；不删除不空置（实测 AI 稿时间锚点密度仅人类的约 1/2.6，具体日期是可信度锚）

## 5. 说教与包装（H1–H8 对应）

| 禁用模式 | 处理 |
|----------|------|
| 很多人觉得 / 你可能以为 | 改数据观察句 |
| 不是…而是… / 真正的问题是… / 本质上是… | 直接陈述，或「宜…不宜…」 |
| 那能不能…? 能。 | 删问答，直给建议 |
| 普通人真正该 / 小白一定要 | 改「建议」「可优先」 |
| 这一步的关键是 / 核心是 | 改具体指标与数值 |
| 效果非常好 / 变化很大 | 改具体指标 |
| 修辞引号「」"" | 去引号直述 |
| 破折号 — – ──、箭头 → | 改逗号、顿号、句号或拆句 |
| 标题式【数据】【结论】【怎么做】 | 改「数据：」「结论：」「建议：」 |
| 见数就加粗 | 正文默认不加粗 |
| ≈ | 约 |

## 6. 通用隐喻（跨行业常见 AI 腔）

| 禁用或慎用 | 替换为 |
|------------|--------|
| 主战场 | 主要服务对象 / 主要路径 |
| 一刀切 | 用同一套标准统一处理 |
| 锚定（非技术术语语境） | 对齐 |
| 交付物是 | 建议落地为 / 宜配置为 |
| 不是越多越好 | 优先保留当前决策真正用得到的变量或材料 |
| 灰度消化（无定义时） | 写明中间分段如何处理 |

## 7. 推荐用词

| 场景 | 用 | 不用 |
|------|-----|------|
| 数据 | 为、达、占、较…高/低 X 个百分点 | 飙升、惊人 |
| 因果 | 与…相关、提示 | 充分证明、决定性 |
| 建议 | 建议、宜、可优先 | 必须立刻、务必马上 |
| 收束 | 总结： | 一句话总结 |
| 材料引用 | 有依据、来源依据 | 有据、证据确凿、一定持有 |
| 未见表述 | 现有交付件中未见明确表述，请确认是否具备 | 对方没有 / 证明不存在 |
| 未核对前 | 不宜…作定论 | 肯定不准、一定更准、严重超标（无数无对照时） |
| 操作指引 | 核对…是否…；…可帮助判断… | 需要特别注意的是、务必深刻理解 |
| 规则摘录 | 1.条件 2.计算 3.结果；公式直写 | 散文抒情式改写规则 |
| 限定说明 | 说明： | 显而易见、毫无疑问 |

## 8. 格式噪声

行尾空格、连续空格、全角空格、零宽字符、重复标点、段间多个空行：一律清理。
全角标点（，。；：）前不留半角空格；中文交付优先全角逗号，避免「万人,合计」类半角混用。

### 12b. 「档」字（请示稿可选加严）

用户要求尽量不出现「档」时，先长后短替换（合法「档案/档期」本稿若无则全清）：

## 20. 交付草稿痕迹（H22）

| 扫描词/模式 | 处置 | 常见改法 |
|-------------|------|----------|
| `需补充完整` `待试算` `待补充最新` `待补数据` | **交付版 Blocker** | 删或改「待确认」（备注/附录） |

## 21. 翻译腔句式硬检（H25 · 命中打回，禁自动互洗）

> 机器只检出；修复=人改或句库替换。禁止「再换一个模型洗一遍」作为唯一放行手段。详见 `production-path.md`。

| 类型 | 扫描模式（例） | 处置 |
|------|----------------|------|
| 欧化长定语 | `通过…进行…从而` `通过…来实现` `以…为手段进行` | **Blocker**（对外） |
| 空转动词 | `进行开展` `予以落实` `予以明确` `完成构建` `做好…工作` `开展…工作` `进行…建设` | **Blocker** |
| 假对称堆砌 | 同页 `一是…二是…三是…四是` 且各条主语/动词骨架同构；或「优势1…2…3…4…5」半页灌满 | **Blocker** |
| 名词串 | `\w{2,}能力\w{2,}建设\w{2,}路径`；连续 ≥3 个双字名词无动词（如「数据整合能力建设路径安排」） | **Blocker** |
| 英文思维残留 | 句首/段首堆砌 `基于` `在…背景下` `作为…的一部分` `围绕…展开`（无具体宾语） | 密集 **Blocker** |
| 空约束词 | 提示或正文仅有 `专业` `全面` `赋能` `抓手` `闭环` `颗粒度` 无动作 | **必改**（删或落具体动作） |

**保留**：真实技术搭配「基于征信报告的变量」；制度「须/不得」；功能枚举「请指示三件事」。

## 23. AI 句式结构（H29 · 中文语料高频句式，词表抓不全）

| 模式 | 扫描特征（例） | 处置 | 常见改法 |
|------|----------------|------|----------|
| 系动词回避 | `作为/充当/标志着 [一个]…` 替代「是」且无真实谓语（「本系统作为行内首个…平台」） | **必改** | 「是」字直述或补真实谓语动作 |
| 否定式排比 | scan `AI否定排比` 12 形态（全表见 rewrite-patterns §37）：不仅仅是…(而|更)是 / 与其说…不如说 / 并非…而是 / 不在于…而在于 / 表面…其实 / 看似…实则 / 以为…其实 / 回头才发现 / 恰恰相反 / 从来不是…而是 / 「A 不重要，重要的是 B」 | **先判方向再改**（rewrite-patterns §37）：Y 比 X 具体=纠错保留改壳；Y 比 X 宏大=拆掉直陈 | 直接陈述 Y，删框架 |
| 三段式凑数 | 同句/同段强行凑三项并列且可并为两项（「稳定性、效率与合规性」无实指递进） | **宜改** | 两项或按真实枚举 |
| 同义词循环 | 同段落同主体连续换称谓无业务理由（主人公→主要角色→中心人物） | **必改** | 全段统一术语（口径一致性优先） |
| 虚假范围 | `从…到…` 两端不在真实尺度（「从战略蓝图到落地细节」） | **宜改** | 改为实指清单或删框架 |

**保留**：真实「作为」介词搭配（「作为贷后监控的补充手段，本方案…」后续有动作）；三项列举确为真实枚举（正文可核对）。三段式与同义词循环需跨句判断，机器只提示、人工裁决。
**复扫（v5.13）**：拆掉否定排比后出现「问题不只在…」「涉及的却是…」「构成…而非…」、分号改写的先压后抬关系，按同骨架处理；仅删除「既 / 也 / 更」而把三项留在同一句，不算完成改写。

## 24. PPT / 总部汇报同构（H31 · 2026-10-21 金服 AI 汇报沉淀）

细则：`ppt-deck-isomorphism.md`。词表速查：

|------|----------|------|----------|
| 段末同构诉求 | 同页连续 ≥2 段以「需要总部给的是」收尾；或三连「请总部支持：」同形 | **Blocker（PPT）** | 三家三种收尾：请总部配套／资源上…优先／这一家请总部先做两件事 |
