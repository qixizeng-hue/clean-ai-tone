# 交付物模式（H18–H22 · 公共核）

> 从「句子润色」升到「交付物级」：客户/业务读的是整份材料，不是单句。  
> 触发：PPT、请示稿、客户汇报、方案终稿；用户说「客户觉得 AI 味」「电报体/翻译风/缩略语」。  
> 细则正反例见 `rewrite-patterns.md` §28–32；扫描词见 `phrase-blacklist.md` §18–20。

## 0. 先问场景（生成前必填，内部可省略输出）

| 变量 | 取值 | 影响 |
|------|------|------|
| 读者 | 客户 / 业务领导 / 模型组 / 内部同业 | 客户版禁内部编号与未解释缩写 |
| 场景 | 客户交付 / 内部讨论 / 技术附录 | 交付版清草稿痕迹；附录可留技术细节 |
| 正式度 | 正式书面 / 半正式 | 正式禁口语隐喻；半正式可略松 |
| 介质 | PPT / Word / 纪要 | PPT 强制「结论标题 + 结论—证据—行动」 |

**优先级（对抗电报体）**：句法完整 > 逻辑连贯 > 读者可懂 > 简洁 > 术语统一。  
禁止把「简洁」放第一——那是电报体的根因。

## H18 · 名词堆叠电报体

**信号**（命中即 Warning；对外交付密集 → Blocker）：

- 连续 ≥3 个名词/动名词短语，仅用顿号/逗号串联，无主语、无「先/再/然后」
- 例：`数据诊断，准入约束入口，决策约束交叉复核与定额，早期逾期确定不良标签定义…`
- 页标题是栏目名而非结论句：`数据诊断发现问题汇总`、`三模型指标总览`

**处置**：

1. 补主语与顺序连接（先…；再…；然后…；最后…）
2. PPT 页标题改成**完整结论句**（断言式，与 H10 兼容）
3. 每页正文按 **结论 → 证据（≤3 点）→ 行动/含义**，禁止整页标签墙

## H19 · 翻译风 / 英文直译句式

**信号**：

- 框式：`通过…的方式` / `在…的情况下` / `由于…的原因` / `对于…而言`
- 虚动词：`进行+双音节动词`、`实现…的提升`、`做出…决定`
- 名词化堆叠：`呈现三点差异`、`须用…分项统计`、`稳健收益客群`
- 长定语「的」链、被动「被…为…」无必要主体

**处置**：优先替换表见 `phrase-blacklist.md` §18；拆成长短句交替的中文流水句；名词化还原为动词。

## H20 · 缩略语墙与术语首次解释

**信号**：

- 正文首次出现 `KS/PSI/WOE/IV/CSI/VIF/AUC/LIFT/PDO/OOT/M1/M2/M3` 等无中文全称+一句人话
- 表头粘连无分隔：`建模AUC建模KS跨期验证KSPSI…`
- 客户版正文出现内部规则号 `R40/R11/R35` 且无业务释义
- 同一概念多名：坏客户/环客户、白户/自户、640/645/680 切点混用

**处置**：

| 读者 | 规则 |
|------|------|
| 客户/业务 | 首次：`中文全称（英文全称，缩写）` + ≤15 字业务含义；后文统一一种叫法 |
| 模型组内部 | 可缩写，但表头必须拆列；口径名全文一致 |
| 客户版正文 | 内部编号改为业务描述；编号可进附录 |

附录术语表**不能替代**正文首次解释（附录太晚）。

## H21 · 数据叙事（数字后必须有「所以呢」）

**信号**：

- 一段内 ≥3 个指标并列，无业务含义句
- 图表下无读图结论；异常分段（如「未知」不良率反高）无解释
- 结论只复述表格数字，无决策含义（对准入/定额/上线/监控意味着什么）

**处置**：

1. 每个关键读数块后补一句含义或动作（不编造数）
2. 异常点必须解释或标「待确认」
3. 禁止「把表里的数再用文字念一遍」当结论

## H22 · 交付场景与内部草稿痕迹

**信号（交付版 → Blocker）**：

- `需补充完整` / `待试算` / `待补充最新数据` / `工作簿未披露`
- 封面/正文 `仅供项目组内…不做正式交付`（若实际给客户）
- OCR/错别字型术语：`环客户`（应为坏客户时）、`低分担绝`、`自户`、`入模拟标`

**处置**：

- 交付版删除或改写为「待确认事项」（放附录/备注，不进客户主文）
- 场景错配：内部讨论稿不得当客户稿交付；须先切换「客户交付」模式重扫 H18–H21
- 疑似错字进「待确认」清单，禁止静默乱改专名

## GATE 判级速查

| 维 | 条件 | 级别 |
|----|------|------|
| H18 | 对外 PPT 名词堆叠 ≥2 页 | Blocker |
| H19 | 翻译框式/虚动词每千字 >3 | Blocker；零星 Warning |
| H20 | 客户版未解释缩写 ≥3 种 或 表头粘连 | Blocker |
| H21 | 关键指标页无「所以呢」 | Warning；决策页无含义 → Blocker |
| H22 | 交付版残留「需补充完整」等 | Blocker |
