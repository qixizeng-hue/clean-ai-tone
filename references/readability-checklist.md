# 可读性审查清单（D8 · R1–R7）

> 目标：降低 AI 生成长文的阅读负荷。**可读性不等于口语化**——在保留专业书面语的前提下控句长、去冗余、优呈现。

## 审查原则

1. 不为「好读」牺牲准确：数值、口径、限定词一个不丢
2. 不改口语聊天体：终稿仍是书面语，只是不绕、不堆、不空
3. 分层适用：P0 对外交付最严，P2 内部草稿可放宽（见档位表）

## R1 句长控制

- 中文单句以 ≤35 字为宜；>60 字记超长句一处
- 判级：超长句每千字 >1 处 → Warning；>3 处或单句 >100 字 → 升 Blocker（严格档）
- 处理：按「一个意思一句」拆分；优先切断处为并列、转折、因果边界

## R2 段落控制

- 单段 >200 字无任何分段 → Warning；P0 场景 >300 字 → Blocker
- 处理：按「一段一个主题」拆段；段首句承担本段主旨

## R3 冗余重复

典型命中（AI 长文高发）：

- 同义反复：一段内换措辞重复同一判断 ≥2 次
- 车轱辘话：删掉后不损失任何信息（无数值、无结论、无动作）的句子
- 铺垫过长：结论前超过 3 句纯背景铺垫

判级：零星 → Warning；重复扭曲重点（读者误以为多处结论）→ Blocker。
处理：保留信息最全的一句，其余删除；不合并改写为更长句。

## R4 结构层级

- 标题层级 >3 级 → Warning
- 空洞标题（「分析」「说明」「展望」「其他」无信息量）→ Warning
- 标题与内容脱节（标题 A 内容 B）→ Blocker（误导性结构）
- 处理：标题写成结论式，如「低分段不良率 8.2%，建议复评阈值」

## R5 呈现优化

- ≥3 项并列信息以连续散文堆砌 → Warning，建议改列表或表格
- 同维对比数据（≥2 组 × ≥2 项）用文字描述 → Warning，建议改表格
- 操作步骤以长段落叙述 → Warning，建议改编号步骤
- 判级：呈现问题通常 Warning；数据对比密集且文字化导致误读风险 → Blocker

## R6 术语与中英混杂

- 同物多名（「模型/算法/评分卡」混指）→ 与 D7 联动，Warning
- 无必要中英夹杂（同一概念中英文交替出现）→ Warning
- 缩写首次出现未展开 → Warning
- 处理：文首或文末建术语对照，全文统一取一个叫法

## R7 信息密度

- 段落无信息增量（全段无数值、无结论、无动作）→ Warning
- 连续 ≥2 段无增量 → Blocker（对外交付）
- 处理：删除或并入相邻段；保留段须至少含一个数值、结论或动作

## 快速评分法（抽样三段）

1. 在文首、文中、文尾各抽一段
2. 数超长句数、无增量句数、最长段字数
3. 定档：

| 档位 | 判定 | 后续 |
|------|------|------|
| A 顺畅 | 抽样三段均无 Warning 级命中 | 通过 |
| B 需局部修 | 命中 1–3 处 Warning | 列入问题清单，FIX 阶段局部修 |
| C 需重排 | 命中 Blocker 级，或 Warning >3 处 | 退回，建议重排结构后再审 |

## 与 clean 模式的关系

clean 直通改写时，R1/R3/R5 作为改写目标之一顺手执行；
GATE 门禁审稿时，R1–R7 逐项审查并出档位与问题定位，D8 档位 C（对外）构成退回条件。
