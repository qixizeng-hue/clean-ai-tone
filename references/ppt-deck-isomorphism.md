# H31 · PPT / 总部汇报同构与收尾排比

> 来源：金服 AI 战略总部汇报 3+2 页文案多轮终审（2026-10-21，V0.2→V1.3.1）。  
> 定位：补机扫与 H29/H30 盲区——**表格感消了，排比换壳又来**；HARD 过关后段末仍像念清单。  
> **事实与数字零改动**；只改语体与句式骨架。

适用：客户/总部 PPT、请示稿、≤5 页讨论底稿；用户说「三连同构」「需要总部给的是」「合并段落后还是像 AI」。

## 0. 改稿副作用（必复扫）

| 上一轮动作 | 易诱发的新腔 | 复扫抓什么 |
|------------|--------------|------------|
| 把「策略 / 资源」两行表合并成叙述段 | **段末同构** | 连续 ≥2 段是否同用「需要总部给的是 / 请总部支持 / 资源诉求是」 |
| 拆掉「不是 A 而是 B」 | 换壳：不求…只求…／问题不只在… | 全文「不是…而是」计数；换壳是否仍 ≥3 |
| 产品列表打散成句 | **起句同构** | 连续「X 是 / X 把 / X 做的是」 |
| 收口从编号改叙述 | 近距重复同一判断句 | 「缩的是…扩的是…」是否在定调+正文各出现一次 |
| 口头补充塞进括号 | PPT 放不下、讲时易忘 | 括号追问是否并入正式「四问／三问」 |

**铁律：合并并行块之后，必须扫段末；扫完段末，再扫「不是…而是」与产品起句。**

## 1. 段末同构资源诉求（本轮主伤）

**命中**：同一页（或相邻三段）客户/试点叙述，**段末句干相同**：

- 「需要总部给的是……」
- 「请总部支持……」（三连同形）
- 「资源诉求：……」（三连同形列表腔）

**改法**：三家（或 N 家）**必须三种收尾句式**，例如：

| 角色 | 可用收尾（错开） |
|------|------------------|
| 甲 | 「请总部配套：A、B、C。」 |
| 乙 | 「资源上，…需要优先…，…也请同步跟上。」 |
| 丙 | 「这一家请总部先做两件事：…；…同步走。」 |

**限额**：同页同干段末 **0 次三连**；两连也宜拆。

## 2. 「不是 A 而是 B」限额（汇报稿加严）

| 场景 | 限额 | 说明 |
|------|------|------|
| 3–5 页总部/客户 PPT | **全文 ≤ 2**（含定调） | 定调可留 1（如「不是简单减人」）；其余改直陈 |
| 长文/研报 | 同 H4 / H29：连续 ≥3 同形 = 必改 | 纠错型可改壳保留 |

**简式也算**（常被漏扫）：`不是…，而是…` / `已经不是…，是…` / `目标不是…，而是…`。  
改法例：「目标不是再谈一家大厂，而是打通…」→「目标很明确：不求再谈一家大厂，只求打通…」；「不是框架全空，而是已有切入」→「这边已经有口子——…」。

**可保留 1 处有力对偶**（与「不是而是」不同构）：如「友商拼的是…，我们拼的是…」。

## 3. 产品 / 能力起句同构

禁止连续三句：`X 是…。Y 把…。Z 做的是…。`  
改法：动词错开——负责 / 把 / 主打 / 覆盖 / 支撑……

## 4. 近距重复判断句

同一判断（如「缩的是…扩的是…」）出现在**定调 + 下一条正文**且相距 <15 行 → 删正文重复，改成「总量没有塌，但结构在换：…在缩，…在扩」等**不同骨架**。

## 5. 正反同拍（一正一反停顿）

「集中在 A，偏少 B」同句一正一反，朗读有一拍空。  
改法：「基本都在 A 这一格；B 还很少。」拆成两拍或改单边陈述。

## 6. 话题跳接缺过渡

分行场景包 → 突然总行组织归口：加半句过渡。  
例：「……属地团队接得住的部分。**另一头，总行的 AI 归口也在普遍落地**，但归口不等于挂牌：…」

## 7. 口头括号并入问句

PPT 不宜：「四问（口头补充：…）」。  
改法：把追问写进第 1、2、4 问正文；括号删除。

## 8. 对外稿禁漏（交付版）

| 避（对外） | 取 |
|------------|-----|
| 待核实 / 内部口径 / 不作对外引用 | 核实前不写进口号；或改「源表未收录，核实前不计入…」 |
| 白嫖（作战台账可用） | 免费驻场共研 / 提前投入换入场 |
| 空转 | 一张纸 / 兑不成实际交付 |
| 不能只等总部 | 与总部形成前后手 |

## 9. 口径数字混用（窄 vs 窄 B）

宽 / 窄 / 窄 B 三列并存时：**正文默认只讲宽+窄**；勿把窄 B 写成窄。  
复扫：表内「窄」列是否与源表「窄口径条数」一致（非窄 B）。

## 自检口诀（PPT 贴版前）

段末三种说法；不是而是 ≤2；产品起句错开；定调勿复读；跳接加过渡；括号并入问；对外无「待核实／白嫖」。
