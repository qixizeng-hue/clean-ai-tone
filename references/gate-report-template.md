# 审稿报告模板（GATE 模式固定输出）

> 每次门禁审稿必须按本模板完整输出，作为 CONFIRM 环节的人工确认依据。

```markdown
# 审稿报告：<交付件名称>

- 审稿日期：<YYYY-MM-DD>
- 交付件类型：<分析报告 / 会议纪要 / 策略说明 / PPT / 操作指南 / 其他>
- 严格度档位：<轻量 / 标准 / 严格>
- 审稿版本：<稿件版本或文件名>

## 总结论

<通过 / 有条件通过 / 退回> —— <一句话核心理由>

## 问题分级清单

| 编号 | 维度 | 级别 | 定位（节/段） | 句摘或数值 | 问题说明 | 建议处理 |
|------|------|------|----------------|------------|----------|----------|
| 1 | D2 | Blocker | §3 第 2 段 | 8.2% | 与上游材料 9.1% 不一致且未标依据 | 核对源数据后修正或标注口径 |
| 2 | D8 | Warning | §1 第 1 段 | 「……」 | 86 字超长句 | 拆为两句 |

## 数值冻结表（D2 登记结果）

| 序号 | 位置 | 指标名 | 数值 | 单位 | 与上游比对 |
|------|------|--------|------|------|------------|
| 1 | §1 | 自动审批通过率 | 64.93 | % | 一致 |
| 2 | §3 | 低分段不良率 | 8.2 | % | **不一致（上游 9.1%）** |

## 可读性评估（D8）

- 档位：<A 顺畅 / B 需局部修 / C 需重排>
- 均句长：<字>；超长句 <n> 处；超长段 <n> 处；无增量段 <n> 处
- 主要问题：<R1–R7 中命中的项>

## 引用核对（D3）

<文内 [n] 与 Sources 对应结果；不适用则写「本项目无引用规范要求，本维不适用」>

## 人工确认区（CONFIRM 环节，用户填写）

| 问题编号 | 处理决定 | 补充要求 |
|----------|----------|----------|
| 1 | ☐ 修复 ☐ 豁免 | |
| 2 | ☐ 修复 ☐ 豁免 | |

> 请逐项勾选「修复」或「豁免」（豁免需给理由或补充要求）。确认后进入 FIX 改稿环节，仅按确认清单执行。

## 签收

- 审稿执行：<Agent / 执行者>
- 人工确认：<用户> 于 <YYYY-MM-DD> 确认
```

## 输出要求

1. 总结论三档只能选一，不许模棱两可
2. Blocker 未清零时禁止给「通过」或「有条件通过」
3. 每个问题必须有定位与句摘，禁止只写「部分段落有套话」
4. 人工确认区空缺时，FIX 环节不得启动
