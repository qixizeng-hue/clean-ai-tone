# H30 · 中文呼吸感（HARD 过关后仍像 AI 时）

> 来源：DeepSeek 对《金融智能体观察》篇一形态切分稿的语体反馈（2026-10-21；含 R3 六条 + R4 微调沉淀）。  
> 定位：补机扫盲区——禁词／破折号已清，但句子工整对称、读三句就累。  
> **事实与数字零改动**；只改语体。

适用触发：用户说「还是很像 AI」「没呼吸感」「工整得累」；或 `scan_ai_tone.py` HARD=0 后人工抽读仍像提纲腔。

## 0. 改后必搜（防回潮）

上一轮已改过的词，**FIX 结束前全文再搜一遍**，禁止同词复发：

| 必搜 | 应无 | 说明 |
|------|------|------|
| `落成` | 做成／形成／变成 | R4 硬伤：R3 已点名，R4 又冒出 → **默认词表 P0** |
| `盖住`（非物理） | 覆盖 | |
| `顺着链滚` | 沿着执行链传导 | |
| `按…看`（归类） | 应归为／归为 | |
| `自行…自行` | 合并为一个「自己…」 | 同词叠用 |

## 1. 「X 的是 Y」密度

禁密集：变的是／看的是／管的是／买的是／要的是／测的是／定归属的是／对准的正是。  
改法：真正变化的是／区别在于／约束…／买方真正想买的，是…（可加逗号拆读）／说明…／招标里写这些条款，针对的正是…；或还原为主语+谓语。  
**限额：全文同类句式 ≤ 2 次。**「真正变化的是」「买方真正想买的，是」可各留 1，其余换动词。

## 2. 「不是 A，是 B」连续对比

对比可用，但 ≥3 处同形连续 = AI 腔。  
改法：意义不在于…而在于…／是两回事／说明…而不只是…；把对比拆到不同句式。  
「而在于：」后尽量**不用冒号**，直接接续。

## 3. 同构短段首

禁止连续多段用等长断言起句（口号清单感）。  
改法：段首改为长短不一的叙述句，核心判断保留、结构错开。

## 4. 「按 XX 看」与归类套话

| 避 | 取 |
|----|----|
| 按生成式看／先按…看 | 应归为生成式 |
| 归类可以这样把握： | 实际归类时，可以看两个信号： |

归类动词要有变化。

## 5. 翻译腔词（默认词表 · 口语自检）

| 避 | 取 | 优先级 |
|----|----|--------|
| **落成**（形态／系统） | **做成** | **P0 必改必复搜** |
| 盖住 | 覆盖 | P0 |
| 跑两遍路径 | 两次运行走过的路径 | P1 |
| 在…里存在 | 在…中出现 | P1 |
| 买的是…看得见 | 买方真正想买的，是…可见性 | P1 |
| 活停在出内容 | 工作到产出内容为止 | P1 |
| 执行仍在人这边／执行在人手里 | 执行仍然靠人 | P1 |
| 顺着链滚 | 沿着执行链传导 | P0 |
| 逼人少上代理 | 限制代理的铺开 | P1 |
| 才划算 | 才具备合理性 | P1 |
| 提醒很清楚 | 结论很明确 | P1 |
| 并非事先画好 | 事先并没有画好 | P1 |
| 代理式跑法 | 代理式的运行方式 | P1 |
| 套到业务 | 套用到业务场景 | P2 |
| 审计所依赖的可复现前提 | 审计要求的可复现 | P2 |

口诀：先问「中文母语者会这么说吗？」→ 改完 **Ctrl+F 落成**。

## 6. AI 高频开头与叠词

「这里」「于是」「怎么 X：」每千字 ≤ 1。  
「自行 A，自行 B」→「自己 A、B」。  
「结果都…；…却…」搭配绕时，改「都…；但…」。

例：「于是要盯的…」→「关注点因此转向…」；「这里模型…」→「在这个例子里，模型…」。

## 7. 术语括注

全文已多次出现的中文专名（如「智能体」），后文不必反复括注英文；英文专名首次出现再括注，或仅在产品名处保留（如授信尽调 Agent）。

## 自检口诀

长短错落、主语明确；少「X 的是 Y」、少「不是 A 是 B」连发；翻译腔词换回口语；**改完搜「落成」**。

## 8. PPT 段末同构与改稿副作用（→ H31）

若本稿是 **3–5 页总部/客户 PPT**，HARD=0 后仍像念清单：优先读 `ppt-deck-isomorphism.md`（**H31**）。  
速查：连续段末「需要总部给的是」；「不是…而是」全文是否 >2；产品句「是/把/做的是」三连；定调句是否在下一段复读。
