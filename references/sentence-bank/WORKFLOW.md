# 成稿路径

## 一、角色分工

| 角色 | 只做 | 不做 |
|---|---|---|
| 口径主笔 | 写中文句、填数、归因、入库 | 不调 PPT 框 |
| 版式 Agent | 贴句、动框、调字号、放图 | 不改句式、不改数 |
| 通顺审稿人 | 出声读，标别扭 | 不改数；改句走人改或句库替换 |

## 二、流程顺序

1. 主笔写 PAGE，或从 ENTRY 拼出 PAGE。  
2. 填 `freeze/NUMBERS.template.md`（可复制为带日期的冻结表），冻结数字与口径。  
3. PAGE / ENTRY 状态改为 `approved`，才允许进客户稿。  
4. Agent 组句、贴句，只动版式。  
5. 真人通顺签字。每页约 2 分钟出声读。  
6. 命中翻译腔句式，打回。禁止「再换一个模型洗一遍」放行。

## 三、页级限额

- 结论不超过 2 句。  
- 建议不复述结论。  
- 禁止半页「一是二是三是四是」同构灌满。  
- 超限拆页或删句。

## 四、翻译腔检出红线

- 欧化长定语：通过…进行…从而实现…  
- 空转动词：进行开展、予以落实、完成构建  
- 假对称堆砌：一是…二是…三是…且同构超过半页  
- 名词串：数据整合能力建设路径安排  
- 英文思维残留：滥用「基于」「在…背景下」「作为…的一部分」

检出后，不改数；改句走人改或句库替换。
