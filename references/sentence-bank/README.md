# 客户认可句库（SSOT）

本库只存客户认可过的中文句、定稿页和冻结口径。  
新稿优先拼句库；没有的增量句，先由主笔写完整中文，再入库。

与 `clean-ai-tone` **H23–H27** 对齐：中文定稿句先于出图；组句不造句；翻译腔句式硬检命中打回；人改或句库替换，禁止多模型互洗。

## 三条铁规

1. 主笔写句，Agent 拼句，机器只检出翻译腔。
2. 数字先冻结，再进句。冻结数字不得在拼句时改动。
3. 客户否定过的句子进 `_archive/`，禁止再拼。

## 三个角色

| 角色 | 只做 | 不做 |
|---|---|---|
| 口径主笔 | 写中文完整句、填数、归因、入库 | 不调 PPT 框 |
| 版式 Agent | 贴句、动框、调字号、放图 | 不改句式、不改数 |
| 通顺审稿人 | 出声读，标别扭 | 不改数；改句走人改或句库替换 |

## 目录说明

| 路径 | 用途 |
|---|---|
| `entries/` | 可复用短句，一条一文件 |
| `pages/` | 一页一文件：数据 / 结论 / 建议 |
| `approved-pages/` | 客户认可页摘录，只读引用（few-shot） |
| `glossary/` | 术语一名一事 |
| `freeze/` | 数字与口径冻结表 |
| `_archive/` | 废弃句，禁止再拼 |
| `_templates/` | 模板空壳，不直接进客户稿 |

## 入库前自检

- 是否完整中文句，主谓齐全
- 是否名词串（如「数据整合能力建设路径安排」）
- 是否欧化长定语（「通过…进行…从而实现…」）
- 是否空转动词（进行开展、予以落实、完成构建）
- 是否假对称堆砌（一是…二是…三是…同构超过半页）
- 是否滥用「基于」「在…背景下」「作为…的一部分」
- 首次缩写是否写全称并解释
- 数字是否已进 `freeze/` 并标冻结

## 主笔 10 条入库口令

1. 先写完整句，再入库  
2. 数字先冻结，后拼句  
3. 一页一结论，标题是结论句  
4. 结论不超过两句  
5. 建议只写动作，不复述结论  
6. 首次缩写写全称，后文统一  
7. 槽位用 `{}`，槽外措辞不改  
8. 客户否定句进 `_archive/`，不再用  
9. 入库前出声读，别扭就改  
10. 禁止中英互译，禁止多模型互洗
