# 可复用短句库

一条一文件。只放客户认可或主笔定稿的短句。  
不放整页定稿，不放未冻结数字的句子。

命名：`SB-场景缩写-序号.md`（如 `SB-问题-001.md`）。  
模板：`_templates/ENTRY.template.md`。

| 子目录 | 场景 | 放什么 |
|---|---|---|
| 01_问题诊断 | 问题诊断 | 不良暴露、迁徙、户数金额不匹配等结论句 |
| 02_能力与基础 | 能力与基础 | 行内自建、数据打通、模型能力等句 |
| 03_角色与定位 | 角色与定位 | 行内与外部分工、职责边界等句 |
| 04_策略矩阵与切点 | 策略矩阵与切点 | 矩阵、中间带、切点细分等句 |
| 05_定额与规则 | 定额与规则 | 定额、刚性扣减、收入比上限等句 |
| 06_试点与行动 | 试点与行动 | 上线、试点、监控、迭代等句 |
| 07_风险与边界 | 风险与边界 | 强制拒绝、共债、信息不可核验等句 |
| 08_封面导语收口 | 封面导语收口 | 封面、导语、收口、请示等句 |
