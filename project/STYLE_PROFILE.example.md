# 项目文风/排版覆盖（示例，请替换）

> 项目层覆盖，叠加在 `core/` 公共核之上。冲突时以本文件为准（见 SKILL.md 冲突裁决）。
> 下列为占位写法。把「示例机构」换成调用方对外名称；不要把未公开口径写进公开仓库。

## 署名与元信息

- 对外署名使用调用方统一对外名称，同一批发布文件保持一致
- 标题、摘要字数按发布渠道限制（示例：标题不超过 32 字、摘要不超过 120 字）

## 外发视角（禁止编辑态泄露）

- 发布稿内禁止内部选题编号、文件名代号、「筹备中」「成稿即发」「还在写」等编辑态表述
- 系列导航只写读者可检索的已发标题，不附内部编号
- 下期预告只写后续可读标题，不暴露未成稿状态

## 事实与合规红线（通用）

- 政策写全称 + 主体 + 月份；案例需可核来源，对不上就删数留趋势
- 第三方口径（融资额、降幅、份额、月活）标注待核或以官方当期文档为准
- 不编造排名、中标金额、未公开经营数字

## 渠道排版（按需启用）

- 若目标平台会剥掉部分样式，背景色用该平台允许的标签承载
- 主色、辅色按调用方视觉规范，不把其他项目的品牌色写进公共核
