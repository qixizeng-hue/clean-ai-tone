# project/ · 项目层覆盖（调用方口径）

本目录存放**调用方专有**的文风/排版/扫描口径，与 `core/` 公共核分离。
复制本包到新项目后，清空示例并写入新项目的覆盖即可，`core/` 不用改。

开源仓库只提供**写法示例**，不含真实机构署名、未公开数据或内部编号清单。

## 本目录示例文件

| 文件 | 内容 |
|------|------|
| `STYLE_PROFILE.example.md` | 覆盖层应写哪些项目专有项（署名、外发视角、编辑态） |
| `scan_config.example.json` | 扫描配置写法：正文 glob + 在公共核规则之上追加项目规则 |

## 覆盖规则

1. **只写项目专有**：通用规则（H1–H8、禁用词、母语审稿）留在 `core/`，不重复
2. **冲突裁决**：项目交付规范 > 公共核默认措辞（见 `SKILL.md` 冲突裁决）
3. **扫描配置**：`scan_config.json` 的 `rules` 会整体替换内置默认，须包含公共核规则 + 项目规则
4. **不写敏感信息**：不含凭证、内部 URL、未发布经营数字、可定位个人的数据

## 复制到新项目三步

1. 复制 `clean-ai-tone/` 到目标 Skill 或项目目录
2. 按本示例写 `STYLE_PROFILE.md` + `scan_config.json`（不要提交真实口径到公开叉）
3. 运行 `python tools/scan_ai_tone.py --base <稿件目录> --config project/scan_config.json` 验证
